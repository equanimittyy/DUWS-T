# Jost*

`Jost-var.ttf` is Jost*, by Owen Earl, published under the SIL Open Font Licence 1.1.

It is here because the promo build scripts need a Futura-class face and Futura BT is
not redistributable. Jost* reproduces the wordmark template's cap height and inked
width to within 0.3%, so the geometry constants in those scripts assume this face.

**Redistribution obligation:** the OFL requires the full licence text to travel with
the font. That text is not in this directory yet — add `OFL.txt` from the upstream
release (<https://github.com/indestructible-type/Jost>) before this repo is published
or mirrored anywhere.
