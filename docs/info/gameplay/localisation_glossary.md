# Localisation glossary

The fixed rendering of each recurring term, one column per language tag, so a concept reads the
same way in every key. A full language pass and a one-string edit both use it; a term missing here
takes the rendering other keys already give it. A rendering applies only where the English means the
sense in parentheses. Address form, punctuation and number format per language are in the
[player-text style guide](player_text_style_guide.md) conventions table.

Inflected languages list the base form; a sentence uses the case or number it needs. A new language
adds a column here in the same change as its pass.
